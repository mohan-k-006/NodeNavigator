# Dataset

## Source
Godot engine source code (MIT licence)
https://github.com/godotengine/godot

## What it contains
- C++ source files from the scene system (scene/main)
- C++ source files from the core object system (core/object)
- C++ source files from 2D physics (servers/physics_2d)
- XML class reference files (doc/classes)

## Collected so far (Week 1)
- 65 files in data/raw
- 10 sample files in data/sample

## Full target
8,400+ source files from the full repository, to be loaded in later weeks.
